# God's Gifts Charity Initiative 

A responsive website developed for God's Gifts Charity Initiative to
provide information about the organization, showcase its programs,
and support online donations.

## Features

- Responsive website design
- Organization information and programs
- Donation/payment functionality
- Contact functionality
- Project and story showcases
- Mobile-friendly interface

## Technologies

- HTML5
- CSS3
- JavaScript

## Live Demo

https://godsgiftscharity.vercel.app/

## My Role

Designed and developed the website, implemented the front-end
